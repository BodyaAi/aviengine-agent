# AmiFlow Agent — Project Context

## Что такое AmiFlow Agent

AmiFlow Agent — это enterprise‑платформа автоматизации выкладки объявлений на Авито.  
Продукт полностью заменяет отдел выкладчиков и обеспечивает:

- публикацию объявлений через официальные API Авито
- обновление объявлений  
- уникализацию текстов  
- Smart‑Migration (массовое копирование объявлений 1:1)  
- анализ отклонений и автоматические исправления  
- работу с шаблонами и вариантами  
- строгую синхронизацию с формами Авито (recording_meta)  
- slot‑based billing (слоты = активные аккаунты)  

AmiFlow — это **AI‑автопилот для Авитолога**, который ведёт аккаунт Авито:  
**публикует, обновляет и уникализирует объявления.**

---

## Основные роли

###  Авитолог (Operator / Manager)
- работает в главной‑панели  
- создаёт шаблоны  
- создаёт варианты объявлений
- запускает AI агента
- запускает Smart‑Migration  
- контролирует публикации   
- отвечает за качество объявлений

### 3. Backend Workers
- публикуют объявления  
- обновляют объявления  
- выполняют Smart‑Migration  
- анализируют отклонения  
- выполняют auto‑fix  
- управляют очередями  
- следят за rate limits  
- ведут аудит и usage‑логи  

---

## Цель AmiFlow Agent

Создать надёжную, масштабируемую и предсказуемую платформу автоматизации выкладки объявлений на Авито, которая:

- полностью заменяет отдел выкладчиков  
- ускоряет публикацию  
- снижает количество отклонений  
- обеспечивает прозрачный billing  
- работает строго в рамках правил Авито
