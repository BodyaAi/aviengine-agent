## 1. Нормализуй переключение светлой/тёмной темы (критично)

Сейчас при переключении темы меняется только фон “за вкладками”, а сами вкладки и часть интерфейса остаются статичными, как будто перекрашены навсегда.

Нужно:

- сделать так, чтобы при переключении темы менялся ВЕСЬ интерфейс:
  - фон приложения
  - фон вкладок
  - карточки
  - текст
  - иконки
  - кнопки
- использовать нативный механизм VKUI:
  - единый верхнеуровневый `<ConfigProvider appearance={appearance}>`
  - при необходимости — `<AdaptivityProvider>` и `<AppRoot>`
- убрать любые локальные/вложенные `ConfigProvider`, которые “застывают” тему для отдельных частей интерфейса
- DevTools Figma — это просто React‑панель, а не нативный Figma UI:
  - она тоже должна получать тему через тот же контекст, а не перекрашивать только фон
  - переключение темы должно менять и DevTools, и основной интерфейс одновременно

Итог: одна точка правды для appearance, один ConfigProvider на уровне приложения, все вкладки и DevTools реагируют на смену темы одинаково.
